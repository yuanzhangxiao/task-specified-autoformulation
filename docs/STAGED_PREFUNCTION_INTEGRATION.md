# Public staged pre-function integration

The versioned `scientific-staged-prefunction-integration-1` campaign combines
the real Level-0 public contract compiler and staged variable/equation topology
proposer before any functional expression is requested. The prospective matrix
is exactly two reviewed Phase-B public cells by three seeds. It uses GPT-OSS-20B
at low reasoning on one warm ACES H100.

For every reviewed mechanism, Level 0 preserves the public pathway sign exactly.
`positive` or `negative` becomes a fixed outer-weight rule only for a direct term
whose selected target and complete grouped source set exactly match the reviewed
target and driver set. `unspecified` becomes `unrestricted`. Every term without
such exact public evidence also defaults to `unrestricted`. The runtime never
multiplies edge labels to infer the sign of an indirect nonlinear path and never
uses hidden equations as evidence.

The equation request displays this runtime-owned policy after the inventory and
left-hand side are frozen. The provider still returns the normal minimal term
schema. Contract-invalid replies retain the existing bounded local retry. A
schema-valid polarity disagreement is accepted as the proposed topology and
scored as a scientific calibration error; it does not trigger silent repair.

Each task reports five separate necessary endpoints:

1. every generated variable has exactly one equation and the topology compiles;
2. every public target is generated;
3. reviewed drivers and required target-composition sources have graph paths;
4. all reviewed mechanism paths, including required dynamic memory, are present;
5. every term follows the conservative public-evidence polarity policy.

These are necessary pre-function checks, not evidence of a good interaction
function or predictive model. The campaign performs no function generation,
parameter fitting, scientific judging, test-data access, private-reference
access, or automatic model selection. Physical calls are cached, tasks are
checkpointed, and a requeued worker resumes without repeating terminal tasks.
