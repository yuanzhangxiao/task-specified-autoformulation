# Public-only pre-fitting audit and localized feedback

The selected function-transport operating point is same-LHS equation batching,
AST-certified outer-gain role repair, and atomic LLM repair only for remaining
invalid terms. The completed hybrid-v2 experiment established transport on one
reviewed opaque-system topology; it did not establish scientific model quality.

This next development experiment consumes those three exact completed candidates
without regenerating them. A CPU-only fact audit first checks source completion,
public topology handoff, exact target/function/latent-initial coverage, source
contracts, and explicit nonlinear obligations. It reports dimensional meaning,
scientific adequacy, dynamic plausibility, parsimony, and initializer meaning as
unresolved rather than manufacturing deterministic verdicts.

One structured GPT-OSS-20B review then assesses exactly six fixed categories:
mechanism/topology, dimensional consistency, dynamic plausibility, functional
semantics, parameter parsimony, and latent initialization. The model may select
public interaction or latent-state anchors, but the runtime chooses the globally
highest-priority failed category. A mechanism/topology failure routes backward
without changing a function. Function and initialization failures permit edits
only to the selected immutable identities. Unmentioned assignments and the full
topology are preserved and checked after compilation. A second review reports
whether the selected category cleared; it is descriptive self-consistency, not
an independent judge or scientific accuracy label.

The frozen source candidate is the paired control for each seed. No parameter
fitting, trajectory metric, scientific judge, test data, or private reference is
used. All terminal failures remain in the denominator, all physical calls and
tokens are retained, and no scalar winner is declared. This pilot decides whether
feedback can be routed and applied locally before expanding the selected protocol
to both public development benchmarks without reviewer-selected topologies.
